## Files

- `index.html`: home screen with the train ticket and route map
- `entry1.html`: Entry 1
- `style.css`: all styling
- `script.js`: route map, Hangul hover headings, photo slots, and the Leaflet map
- `images/`: photos for each entry

## Features

- Subway route map where locked stations open as entries are published
- Train ticket with passenger name, date, and destination
- Headings that switch between English and Hangul on hover (or tap on phones)
- Interactive map of Korea built with Leaflet and OpenStreetMap
